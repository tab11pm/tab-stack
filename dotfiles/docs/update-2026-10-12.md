# October 12 desktop source update

This export carries selected installed desktop source into tab-stack on top of
its existing monitor, music, battery, DeepSeek and OpenCode changes. Private
profiles, activity history, credentials, integrations, wallpapers and backups
are excluded. Publication does not install, reload, lock or suspend a desktop.

## Controls

- **Alt+Tab / Alt+Shift+Tab** opens the MRU window switcher. Alt release, Enter
  or a click selects a window; Escape cancels. Reverse selection and wrapping
  also work while the workspace reply is pending. Native modifier-release
  handling still needs graphical acceptance on the pinned compositor.
- **Super+Ctrl+Shift+W** opens the fullscreen widget layout editor. Create, copy,
  rename or remove layouts, add/remove widgets and move them between displays.
  Arrow keys move a focused widget. The empty preset is protected; existing
  presets seed a new library. The wallpaper picker also selects these layouts.
- **Super+Ctrl+T** pauses/resumes local activity accounting. The activity widget
  displays day/week totals, hourly/daily bars and application shares. Tracking
  pauses after five idle minutes, on lock or disconnection. Viewing mode counts
  passive viewing and inhibits this shell's automatic sleep; manual pause wins.
- The system panel has **Night light** controls for temperature, local-time
  scheduling and temporary overrides. The filter shares an overlay with CRT or
  aquarium effects, reports failures and resumes after authenticated unlock.
- The panel has **Automatic sleep** controls for 1/5/10 minutes. It is disabled
  by default in publication. Enabling it requires a successful secure lock before
  suspend, respects idle inhibitors and cancels when activity resumes.

Floating windows follow monitor-origin changes and are kept inside the viewport
when restored. MateEngine's oversized transparent surface remains exempt.
Screenshots fall back to slurp/grim/wl-copy when Flameshot is unavailable. Ghostty
uses Bash and matching shell integration. NumPy accelerates the music spectrum
but a Python FFT fallback keeps it usable without NumPy.

Hermes remains opt-in. `SHOJI_HERMES_LAUNCHER` can name a locally configured stdio
transport executable; no SSH endpoint, transport script or credentials are
bundled. The existing local Hermes virtual environment remains the fallback.

## Private persistent files

`night-light.json`, `idle-sleep.json` and `widget-layouts.json` stay in the installed
shell directory. They are excluded from source publication and preserved on
reinstall, alongside existing monitor/wallpaper profiles and integration files.
Activity intervals and app IDs stay in `$XDG_STATE_HOME/shoji-shell/activity.sqlite3`
(default `~/.local/state/shoji-shell/`), with private directory/file permissions.
No window titles, browsing history or credentials are stored by the tracker.

Layout-library saving precedes selection saving. If the latter fails, the live
session keeps the previous published library, but a restart loads the library
already written to disk. Review the library after a failed save before restarting.

## Optional login/session components

The [independent session](session.md) adds a separately selected session installer,
a native logout helper, ownership checks and scoped service cleanup. Its default
installation is unchanged: choose `--component session` explicitly. The legacy
session remains available. The [X11 greeter](greeter.md) is a separate optional
system configuration; it does not change the desktop's Wayland protocol.

## Source checks

```bash
node dotfiles/scripts/check-switcher.mjs
node dotfiles/scripts/check-widget-layouts.mjs
node dotfiles/config/shoji-shell/check-night-light.mjs
python3 dotfiles/config/shoji-shell/activity-tracker.py --self-check
python3 dotfiles/config/shoji-shell/music-spectrum.py --self-check
node dotfiles/scripts/check-monitors.mjs
python3 dotfiles/config/shoji-shell/brightness.py --check
python3 -B -m unittest discover -s dotfiles/tests -p 'test_session_*.py' -v
bash dotfiles/scripts/build-shaders.sh
python3 dotfiles/scripts/check-install.py
python3 dotfiles/scripts/check-public.py --staged
```

The compositor night-filter check is `config/shojiwm/scripts/check-night-light.mjs`.
It needs the installed `shoji_wm` TypeScript package and a TypeScript-aware ESM
loader (or Bun), run with the compositor config directory as the working directory.
It installs a fake native overlay bridge and never connects to desktop IPC.
A TypeScript typecheck uses the installed compiler and runtime imports, without
an implicit package download. See [validation](validation.md) for check results
and the graphical/clean-machine acceptance that remains outstanding.
